## Reporting a Vulnerability

The TrustSentry team takes the security of cryptographic verification and user data seriously. If you discover a security vulnerability or bypass in the 7-stage verification engine, signature parsers, or quarantine gate:

1. **Do not disclose the issue publicly** in GitHub issues or discussions.
2. Email full technical details and reproduction steps to the repository maintainer or project security team.
3. Include:
   - Nature of the vulnerability (e.g. signature spoofing, parser crash, memory leak, SSRF bypass).
   - Sample payload or reproduction artifact.
   - Device and Android OS version tested.
4. We will acknowledge receipt within 48 hours and coordinate a coordinated disclosure timeline.
